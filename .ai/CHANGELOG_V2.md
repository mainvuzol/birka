# Changelog v2 — Product Excellence Edition

## Philosophy
Apply 80/20: preserve the original engineering organization, but formalize the small set of additional capabilities that disproportionately improve a real POS/inventory product.

## Added
- 24 Product Excellence skills covering performance, resilience, multi-tenancy, inventory history, observability, recovery and release quality.
- `PRODUCT_EXCELLENCE_STANDARD.md`.
- `80_20_OPERATING_PROFILE.md` and `profiles/core-80-20.md`.
- performance budget and SLO templates.
- production-readiness workflow.
- stronger release checklist and constitution laws.

## Intentionally not added as mandatory architecture
- microservices;
- Kafka;
- Kubernetes;
- Elasticsearch;
- Redis-by-default;
- separate databases per module.

These remain optional responses to measured needs, not default complexity.
