# «Усе на бірці» — исходники главного дизайна

Главный дизайн «Бирки» с 2026-10-27; выжимка и граница принятого — [`../design-direction.md`](../design-direction.md). Здесь — то, по чему его строить.

| Файл | Что это |
|---|---|
| [`concept-spec.md`](concept-spec.md) | Полная спецификация концепта (английский, 2026-10-22): концепт, персона, принципы, навигация, токены, компоненты, голос, 29 экранов с текстами EN/UA, данные и сценарии демо, план холста, предложения и вопросы владельцу. |
| [`tokens.css`](tokens.css) | Все токены §5 как CSS-переменные: светлая тема на `:root`, тёмная — под `prefers-color-scheme` и `[data-theme="dark"]`; шрифты, отступы, радиусы, размеры, движение, слои. Сгенерирован для демо. |
| [`icons.js`](icons.js) | 61 иконка §5.9 (сетка 24, обводка 1.75, `currentColor`): `Birka.icons[name]` — SVG без обёртки. Сгенерирован для демо. |

Как читать спецификацию:
- Пометки: **[EXISTS]** — уже есть в продукте и утверждено; **[PROPOSAL]** — новое, ждёт ответа владельца; **[DEVIATION]** — отступление от направления 2026-10-11; **[Q-n]** — вопрос владельцу (§12.4). С 2026-10-27 отступления — это и есть направление; предложения по-прежнему ждут ответов (`design-direction.md` §9, там же что строить до ответа).
- Персона (Людмила Коваль) и все данные §9 (модели, суммы, заказы, люди, часы) — **демонстрационные**, не факты о бизнесе. §9–§11 — данные и план для демо и холста, для приложения не нужны.
- Спецификация упоминает `spec/tokens.json`, `spec/demo-data.json`, `spec/icons.json` и скрипты `work/spec-tools/` — их здесь нет: токены и иконки сохранены как `tokens.css` и `icons.js`, данные демо — в §9.
- В `tokens.css` блоки `[data-thread="olive"]` — переключатель демо «лайм / олива» (вопрос Q-2, решён: лайм); в приложение не переносить. Переменные `--tg-*` — для рисования чужого интерфейса Telegram в демо, в приложении не нужны.

Происхождение: временная папка, где концепт собирался, была очищена системой; 2026-10-27 спецификация восстановлена построчно из чтений агентов, работавших с ней после последней сборки (все 2 434 строки, без пропусков и расхождений, 219 999 символов — столько же, сколько при сборке), `tokens.css` и `icons.js` — из опубликованного демо.
