# Дизайн-направление «Бирки» — эталон

Статус: **концепт этапа 1 одобрен владельцем 2026-10-11** как направление («уже логичный вариант»). Детали навигации и вида ещё можно уточнять; этап 2 (остальные разделы) не нарисован.
Холст: https://claude.ai/artifact/NaGsrLVDdNpmnXSGP72ZK9 (страницы «Стратегия» и «Экраны»; приватный, у агента доступа нет — источник истины для агента этот файл).
Любое отступление от этого файла в ТЗ — только с пометкой «отступление от направления» и причиной.

## 1. Что мы поняли
- Логика продукта сильная (долги, слепой пересчёт кассы, бумага при сбое, брак, заказы с доставкой), подача — «бухгалтерская анкета»: 17 кнопок разделов над каждым экраном у владельца (10 у продавца), ≈560 заголовков/кнопок/полей видно почти сразу, 0 закреплённых кнопок, продажа 5–6 касаний.
- **Инсайт:** продавцу не нужна система учёта — ему нужно продать, пока покупательница рядом, и не бояться ошибиться.
- **Идея:** «Бирка — тихий помощник у прилавка. Один экран — одно дело. Всё сложное есть, но появляется только когда нужно.»

## 2. Пять принципов (критерии каждого экрана)
1. **Одно дело на экран.** Продажа = поиск → размер → способ оплаты. Остальное прячется.
2. **Частое на виду.** Пять вкладок внизу по правам человека; редкое — в «Ще» и шторках.
3. **Цифра крупно.** Сумма, размер, остаток — главное на экране; слова короткие.
4. **Палец внизу.** Меню и главные кнопки — в нижней трети.
5. **Правила невидимы.** Человек видит только своё; никаких «Немає права» — просто нет лишнего.

**Бюджет экрана (без открытых шторок):** заголовок + максимум одна строка контекста; один переключатель режима; одно поле поиска/ввода; список или карточка; одна зона главного действия. Поясняющий текст — не больше одной строки на экран. Всё остальное (цена, количество, «частинами», редкие действия, история) — в шторке, на детальном экране или в «Ще». Нельзя переносить пункты ТЗ на экран «как есть»: каждый видимый элемент должен быть нужен в эту секунду.

## 3. Навигация: 17 кнопок сверху → 5 вкладок снизу
Вкладки = четыре самых частых дела, разрешённых человеку, + «Ще». Ни одна вкладка и пункт не показываются без права.

| Роль | Вкладки |
|---|---|
| Продавец | Продаж · Товар · Клієнти · Каса · Ще |
| Менеджер | Огляд · Продаж · Товар · Клієнти · Ще |
| Владелец | Огляд · Продаж · Товар · Клієнти · Ще |

| Было (кнопка сверху) | Стало |
|---|---|
| Продаж | Продаж |
| Повернення | Продаж › переключатель «Повернути» |
| Замовлення, + Нове замовлення | Клієнти › «Замовлення» (кнопка «+» в заголовке) |
| Борги | Клієнти › «Борги» |
| Залишки | Товар (модель целиком) |
| Приймання | Товар › плитка «Прийшов товар» |
| Брак | Товар › плитка «Брак» (счётчик ждущих) |
| Каса | вкладка «Каса» у продавца; Ще › Гроші у менеджера/владельца |
| Звіт | Огляд (сводка) и Ще › Гроші › «Звіт про продажі» |
| Накладні, Постачальникам, Позичене | Ще › Постачальники / Гроші |
| Каталог (перевірка), Моделі | Ще › Товар і каталог |
| Початкові залишки | Ще › Товар і каталог (счётчик на затвердження) |
| Магазини, Резервні копії | Ще › Мережа; статус копий — в «Огляді» |
| «Змінити магазин» | внизу «Ще», только при двух и более магазинах |

## 4. Дизайн-система
Шрифт — системный (как в Telegram), `font-variant-numeric: tabular-nums` для всех сумм и количеств. Светлая и тёмная тема обязательны; тема берётся из Telegram (`colorScheme`), фирменный акцент один.

**Цвет — светлая:** фон `#F4F4F1`, поверхность `#FFFFFF`, поле `#EEEEEA`, текст `#121715`, вторичный `#5E6662`, линия `#E7E7E2`, акцент `#0F6E58` (текст на нём `#FFFFFF`), акцент мягкий `#E2F0EB`.
Смысловые: долг `#A33A0B` / фон `#FBEBE3`; предупреждение `#7A4E0B` / `#FBF1DE`; в пути `#1E4E79` / `#E3EEF8`; брак `#5B2E7A` / `#F1E9F6`.
**Цвет — тёмная:** фон `#0E1513`, поверхность `#18211E`, поле `#222C29`, текст `#F1F4F2`, вторичный `#9AA5A0`, линия `#26312D`, акцент `#38B28F` (текст на нём `#0B1210`), акцент-текст `#6FD3B4`, мягкий `#173A31`, долг `#F08A5D`, предупреждение `#E2B34A`.

**Шрифт (px/вес):** заголовок экрана 32/800 (−0.9) · заголовок детали 28/800 · заголовок шторки 22/800 · строка списка 17/700 · текст 16 · пояснение 15 · мета 14 · подпись раздела 13/700 (+0.4) · подпись вкладки 11/600–700.
**Деньги:** целая часть крупно 800 (26 на панели, 34–42 в карточках, 48–54 на чеке/пересчёте), «,00 грн» мельче и вторичным цветом; формат `1 850,00 грн`, неразрывные пробелы.
**Размеры:** касание ≥ 44 px; главные кнопки 54–56 px высотой, радиус 15–16; поиск 52; чип размера 48×52; вкладки 84 (с safe-area); отступ экрана 16, промежутки 14.
**Радиусы:** карточки 20–24, поля и кнопки 14–16, чип 14, статус-пилюли 999, шторка 26 сверху.
**Иконки:** линейные, обводка 1.8–2, одно семейство; эмодзи нет.

## 5. Компоненты
- **Нижнее меню** — 5 вкладок с иконкой и подписью, активная — акцентом.
- **Переключатель режима** (сегменты на сером поле): «Продати / Повернути», «Борги / Замовлення», «Сьогодні / Тиждень / Місяць».
- **Поиск** — белое поле 52 px с иконкой, подсказка «Модель або колір».
- **Строка модели** — цветная точка, название, цвет вторичным, цена мелко; справа чипы размеров «M / 3 шт».
- **Чип размера** — серый; в корзине — акцентный с «×N».
- **Панель оплаты** — плавающая карточка над меню: что продаём + сумма крупно; три кнопки «Готівка / Картка / Переказ». Появляется только когда в корзине есть товар.
- **Шторка** — для редкого: корзина (−/+, цена, «прибрати», переключатель «Оплата частинами» с именем, телефоном, суммой сейчас), нехватка товара.
- **Строка списка** — аватар-инициал/иконка, заголовок, подпись, значение справа, шеврон.
- **Статус-пилюли** — «До відправлення», «Відправлено», «Прибув на пошту», «Клієнт забрав», «Винні …», «Брак · перевірка».
- **Плашки состояния** — «Сервер не відповідає. Продаємо на папері…» (предупреждение), «Продаж записано. Двічі він не запишеться» (успех).
- **Экран результата** — большая галочка, сумма крупно, пилюля способа («Картка — проведіть на терміналі»), «Новий продаж», тихое «Помилились? Оформити повернення».

## 6. Экраны этапа 1 (эталон)
- **Продаж:** заголовок + магазин; «Продати / Повернути»; поиск; модели с чипами размеров. Касание размера кладёт в корзину → панель оплаты → чек. «Повернути»: поиск «Що повертають?» и сегодняшние продажи магазина **без сумм и способов**.
- **Нехватка:** шторка «В обліку N шт., а продаєте M» → «Є на полиці — продати M» / «Немає — прибрати з кошика» + «скажіть менеджеру» (у продавца нет права списывать нехватку).
- **Товар:** плитки «Прийшов товар», «Брак (N чекають)»; поиск; модели с размерами и итогом. Деталь модели: цвет, цена продажи, размеры «N доступно / N у резерві замовлення», другие склады, «Брак»; кнопка «Продати». Менеджеру — ещё «Змінити ціну», «Виправити залишок», «Інвентаризація».
- **Клієнти › Борги:** «Магазину винні» крупно + сколько людей; поиск «Ім’я або телефон»; список с суммами цветом долга. Деталь: остаток крупно, прогресс «Сплачено X з Y», «Внесок» с «Увесь залишок» и тремя кнопками способа, история.
- **Клієнти › Замовлення:** «+» в заголовке; группы «Потрібно відправити», «В дорозі»; строка: № и клиент, статус, товар, перевозчик и ТТН.
- **Каса (продавец):** «Каса відкрита · останнє закриття …»; большая тёмная карточка «Закрити касу» («скільки мало бути — покажемо після підрахунку»); «Видати з каси» (витрати, кур’єру постачальника); «Змінити спосіб оплати». Пересчёт: одно большое поле суммы, «Поки рахуєте, не продавайте», напоминание про бумагу. После: «Мало бути / Порахували / Нестача|Надлишок», картка и переказ, причина при расхождении.
- **Огляд (владелец, менеджер):** период; тёмная карточка «Продано з урахуванням повернень» + по способам + по магазинам; «Вам винні клієнти», «Ви винні постачальникам»; «Варто глянути» (брак, списки на затвердження, каталог, резервные копии).
- **Ще:** группы «Гроші», «Постачальники», «Товар і каталог», «Мережа»; счётчики там, где что-то ждёт; «Змінити магазин».

## 7. Правила, которые дизайн обязан держать
Слепой пересчёт (продавец до пересчёта не видит продаж с суммами и способами — G32; после — G27). Одна продажа — один способ оплаты (G36). Пока считают кассу — не продают (G37). Продавец не видит финансовый отчёт (`report:view_financial`). «Товар на місці» для товара на полке без учёта. Продавец выдаёт из кассы только на расходы и курьеру поставщика (G34). Взнос долга — тремя кнопками способа (G23). Продажа на бумаге при сбое с отметкой. Права и правила проверять по `backend/app/modules/authz/permissions.py` и `.ai/project-memory/business-rules.md` — они главнее этого файла.
