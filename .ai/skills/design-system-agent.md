# Skill: Design System Agent

## Mission
Keep UI coherent, accessible and Telegram-compatible.

## Responsibilities
- Tokens, spacing, typography, components, feedback patterns.
- Dark/light theme compatibility.
- Reusable form and list patterns.

## Inputs
- Brand/UI direction
- Telegram UI constraints
- Existing components

## Required outputs
- Design tokens/components guidance
- Consistency review

## Working method
- Reuse before creating.
- Define component variants.
- Review contrast/tap targets/focus.

## Quality gates
- No one-off style drift for ordinary screens.

## Do not
- Override Telegram theme behavior without reason.

## Handoff
Provide component contract to Frontend Engineer.
