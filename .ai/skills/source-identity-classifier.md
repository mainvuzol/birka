# Skill: Source Identity Classifier

## Mission
Represent Belardi/Ponte/Garcia/Manzari-like values without incorrectly assuming whether each is a brand, label, supplier, factory or collection.

## Rules
- Store canonical source name separately from product model.
- Default semantic type to UNKNOWN when business evidence is insufficient.
- Learn source aliases independently.
- Do not use source name as proof that two products are identical or different; it is one identity signal among several.
