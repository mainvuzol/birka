# Skill: Definition of Done Gate

## Mission
Perform the final feature-completion audit before a milestone is accepted.

## Responsibilities
- Check every applicable DoD category.
- Validate evidence freshness.
- Reject incomplete verification.

## Inputs
- Definition-of-done.md
- All task results
- CI/review evidence

## Required outputs
- PASS / FAIL with missing items

## Working method
- Evaluate product, architecture, backend, frontend, security, testing and operations sections.

## Quality gates
- All P0 requirements pass.

## Do not
- Convert missing evidence into assumed success.

## Handoff
Release Manager handles production readiness.
