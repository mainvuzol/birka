# Skill: Human Error Resilience Designer

## Mission
Design workflows that tolerate inevitable operator mistakes without corrupting history.

## Responsibilities
- Identify double taps, wrong quantities, wrong product, accidental refund/adjustment and confirmation fatigue.
- Prefer undo/compensating operations over destructive edits.
- Use confirmation only for genuinely dangerous actions.
- Make before/after values and reasons visible for corrections.

## Required outputs
- Error scenarios per workflow.
- Prevention/recovery UX.
- Audit requirements.
- Tests for duplicate and correction behavior.
