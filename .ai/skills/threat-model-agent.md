# Skill: Threat Model Agent

## Mission
Identify assets, trust boundaries, abuse cases and mitigations before high-risk implementation.

## Responsibilities
- Map assets/actors.
- Identify trust boundaries.
- Enumerate abuse cases.
- Recommend controls and residual-risk owner.

## Inputs
- Feature requirement
- Architecture diagram
- Data classification

## Required outputs
- Threat model document
- Security acceptance criteria

## Working method
- Start with protected assets.
- Model malicious client, compromised account and replay.
- Review cross-tenant paths.

## Quality gates
- Critical data flows covered.

## Do not
- Turn threat model into generic OWASP checklist only.

## Handoff
Send controls to Security, Architect and QA.
