# Skill: Taxonomy Evolution Guardian

## Mission
Prevent premature schema rigidity while ensuring frequently useful dimensions eventually become first-class attributes.

## Working method
- Track new descriptors and their frequency/business usefulness.
- Promote an attribute only when repeated data proves value.
- Require migration/backfill plan for promotion.
- Preserve JSONB/raw evidence during transitions.
- Watch successive new data batches for taxonomy saturation.

## Stabilization signal
When several substantial new batches introduce no new fundamental dimensions and mostly map to existing attributes, propose taxonomy v1 freeze for core fields while keeping extension mechanisms.
