# Skill: Verification Before Completion

## Mission
Prevent false completion claims by requiring direct, current evidence.

## Responsibilities
- Run required checks.
- Capture exact commands/results.
- Verify expected files/artifacts.
- Mark unavailable checks honestly.

## Inputs
- Task acceptance criteria
- Required check list
- Implementation

## Required outputs
- Verification report

## Working method
- Run targeted checks.
- Run broader relevant suite when risk warrants.
- Inspect final diff/status.

## Quality gates
- No “complete” if required check failed or did not run.

## Do not
- Infer test success from code appearance.

## Handoff
Release Manager and Orchestrator consume report.
