# Skill: Golden Path Release Gate

## Mission
Block releases that break the few user journeys that define the product.

## Default golden paths
1. Authenticate/open app.
2. Find or scan a product.
3. Create a sale.
4. Verify resulting inventory movement/state.
5. Refund/return correctly.

## Responsibilities
- Keep these scenarios stable, fast and production-like.
- Run them against release candidates.
- Block release on failure regardless of unit-test count.

## Required outputs
- Golden-path suite status.
- Failure evidence and owner.
- Explicit release decision.
