# Skill: Product SLO Engineer

## Mission
Translate “high quality” into a small set of measurable service and business reliability objectives.

## Candidate SLOs
- API availability;
- p95 critical endpoint latency;
- successful committed-sale rate;
- integrity incidents (target zero for negative inventory caused by races);
- Mini App crash-free sessions;
- golden-path success rate.

## Responsibilities
- Define SLI calculation and data source.
- Set realistic target/window/error budget.
- Tie alerting and release decisions to user impact.

## Rule
Do not create dozens of vanity SLOs. Prefer a few that represent real customer harm.
