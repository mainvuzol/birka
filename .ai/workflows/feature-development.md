# Workflow — Normal Feature

1. Executive Orchestrator frames objective and risk class.
2. Product Strategist defines user outcome and acceptance criteria.
3. Requirements Engineer converts criteria to testable invariants.
4. Architect decides whether architecture/API/schema changes are required.
5. Task Planner builds a dependency graph.
6. Specialists implement in dependency order; safe independent work may run in parallel.
7. QA/Test Engineer adds/updates tests.
8. Independent Code Reviewer reviews the diff.
9. Security/Concurrency review runs when relevant.
10. Implementer fixes findings.
11. Verification skill runs required commands and records evidence.
12. Documentation Agent updates durable docs.
13. Release Manager decides READY/BLOCKED.
