Запусти агента `birka-redesign-strategist` для аудита и ТЗ на редизайн.

Объём: $ARGUMENTS (если пусто — весь клиент).

Если в аргументах есть «скриншоты» — сначала спроси пользователя, можно ли запускать приложение / Playwright, и передай агенту ответ. Без явного «да» агент работает только по коду.

Когда агент закончит: перескажи пользователю резюме, P0 и вопросы владельцу, дай ссылку на файл ТЗ. Код не меняй, пока пользователь не выберет, какие задачи брать в работу.
